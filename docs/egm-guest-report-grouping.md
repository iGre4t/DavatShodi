# گروه‌بندی گزارش‌های مهمانان

گزارش‌های یک مهمان در یک بازه با وضعیت، نوع عملیات و اثر یکسان، یک رخداد نمایش داده می‌شوند. متن و زمان متفاوت اسکن، رخداد تازه نمی‌سازد. تعداد تکرار و آخرین زمان روی کارت دیده می‌شود. وضعیت‌های متفاوت، مانند ورود بدون دعوت و خروج اجباری، جدا می‌مانند. گروه‌بندی قبل از فیلتر و صفحه‌بندی انجام می‌شود.

ورود تکراری گزارش مدیریتی جدید نمی‌سازد؛ لاگ اسکن اصلی حفظ می‌شود. ردیف‌های قدیمی تکراری نیز از فهرست مدیریت کنار گذاشته می‌شوند.

تصمیم فعلی مهمان تعیین می‌کند کدام رخداد قابل اقدام است. گزارش‌های قدیمی که با تصمیم جدیدتر جایگزین شده‌اند، فقط برای اطلاع نمایش داده می‌شوند و دکمه ویرایش ندارند. فیلتر «صرفاً اطلاع‌رسانی» اضافه شده است. لینک‌های قدیمی گزارش تکراری به رخداد اصلی هدایت می‌شوند؛ بررسی و بازگشایی، نسخه‌های همسان را با هم تغییر می‌دهد. پیام‌های ربات مربوط به نسخه‌ها برای تازه‌سازی علامت‌گذاری می‌شوند.

هیچ لاگ یا گزارش اصلی حذف نمی‌شود و SQL دستی لازم نیست. این تغییر فعلاً محلی است.
